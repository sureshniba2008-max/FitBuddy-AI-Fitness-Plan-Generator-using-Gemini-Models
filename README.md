# FitBuddy – AI Fitness Plan Generator Using Gemini Models

FitBuddy is an automated health and fitness web application designed to generate personalized workout splits and balanced nutrition plans based on an individual's biometric inputs, experience level, and physical goals.

---

## 📌 Project Overview
Achieving consistent health and physique goals requires tailored planning that matches unique body metrics and dietary needs. FitBuddy evaluates user data to compute Body Mass Index (BMI), visualizes health categorizations, and generates 7-day structured training splits alongside macronutrient-focused daily meal plans with real-time visual exercise guides.

## ✨ Key Features
* **Real-Time BMI Analysis:** Calculates exact Body Mass Index (BMI) using height and weight, categorizing individuals into Underweight, Normal, Overweight, or Obese.
* **Goal-Oriented Workout Routines:** Creates customized 7-day split schedules across fat loss, muscle building, and endurance stamina.
* **AI Visual Exercise Guides:** Dynamically renders contextual visual references for movement guidance.
* **Personalized Nutrition Blueprints:** Details daily meal breakdowns (Breakfast, Lunch, Pre-Workout Snack, Dinner) suited for Vegetarian, Vegan, High-Protein, and Balanced diets.
* **Zero-Dependency Deployment:** Built with single-file responsive architecture (HTML5/CSS3/JavaScript) running smoothly via GitHub Pages without API quota limits or server down-time.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Modern Responsive Dark Layout)
* **Core Logic:** JavaScript (ES6 Client-side Processing & Computational Modeling)
* **Visual Synthesis Engine:** Dynamic contextual exercise image rendering
* **Hosting & Deployment:** GitHub Pages
